# Proteções e conformidade

O Roda agora possui campos para faixa etária, estado de verificação e identificação de conta de menor. Quando `is_minor` está ativo, a interface força filtro de conteúdo e mensagens diretas somente entre amigos.

Ainda dependem de fornecedor e análise jurídica antes de serem liberados como verificação definitiva:

- verificação de idade que não dependa apenas de autodeclaração;
- fluxo de consentimento e supervisão parental;
- prazos de retenção e exportação de dados;
- atendimento e triagem das denúncias.

Nenhum documento de identidade deve ser armazenado no banco do Roda. Dados de verificação de idade devem ser usados somente para essa finalidade.
